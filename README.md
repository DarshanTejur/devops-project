 DevOps Monitoring Dashboard

A full-stack DevOps project demonstrating containerized deployment, CI/CD automation, and monitoring using Docker, GitHub Actions, and Prometheus.

Features

* Frontend + Backend + MongoDB integration
* Dockerized multi-container application
* CI/CD pipeline using GitHub Actions
* Prometheus monitoring setup
* Real-time API metrics tracking
* Deployment task dashboard
* REST API integration

This project was built to understand how real-world DevOps workflows work in practice. I created a full-stack application where the frontend, backend, and MongoDB database run inside separate Docker containers, making the application portable and easy to manage. I used Docker Compose to connect and run all services together with a single command. To improve automation, I integrated GitHub Actions for CI/CD so that code changes can be automatically built and managed through workflows. I also implemented Prometheus monitoring to track backend metrics such as API requests, status codes, and service health in real time through the /metrics endpoint. This project helped me gain hands-on experience with containerization, automation, monitoring, and deployment concepts that are commonly used in modern DevOps environments.
